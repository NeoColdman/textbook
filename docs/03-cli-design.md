# 命令行与交互设计

本文记录已实现的命令与交互规范。项目名 `textbook-cli`，Python 包名 `textbook_cli`，命令名 `textbook`。已验证范围与待验证事项以[实现与验收记录](06-implementation-status.md)为准。

运行环境为 Python 3.10+，支持 Windows、macOS、Linux，不依赖图形桌面或 Tkinter。MVP 只下载电子教材 PDF；音频、课程、自动登录、HTTP Range 续传及跨次任务恢复不在首版范围内。

## 1. 入口与命令

```text
textbook
textbook browse [--query TEXT]
textbook search QUERY [--stage TEXT] [--subject TEXT] [--edition TEXT]
                      [--grade TEXT] [--limit N] [--offset N] [--json]
textbook download [URL ...] [--id ID ...] [--input FILE]
                          [--output DIR] [--bookmarks] [--jobs N]
                          [--overwrite] [--credentials-file FILE] [--json]
textbook catalog refresh
textbook catalog status
textbook auth import [--file FILE]
textbook auth grab
textbook auth status
textbook auth clear
textbook doctor
```

全局提供 `--help` 和 `--version`。上面的 `--id ID ...` 表示 `--id` 可以重复，每次接收一个 ID；位置参数只接收平台教材页面 URL，不接收 PDF 直链。`--input` 接收 UTF-8 文本文件，每个非空行一个页面 URL 或资源 ID；`--input -` 明确表示从标准输入读取。

### TTY 行为

| 情况 | 约定 |
| --- | --- |
| 无参数，标准输入与标准错误均连接终端 | 进入带 `❯` 提示符的交互主页 |
| 无参数，任一上述流不是终端 | 帮助写入标准错误，退出 2 |
| `browse` 在非交互环境执行 | 说明需要终端，退出 2 |
| 显式执行 `search`、`download` 等非交互命令 | 按参数执行，不因存在终端而增加问题 |
| 非 TTY 下缺少必要输入或凭据 | 返回错误，不弹出问题、不启动浏览器 |
| 设置 `NO_COLOR` 或标准错误不是终端 | 禁用颜色、光标控制和动态进度条 |

除明确交互的 `browse` 外，显式命令永不等待未声明的交互输入。`auth import` 无 `--file` 时仅在 TTY 中通过隐藏输入读取凭据；非 TTY 下提示使用 `--file` 并退出 2。`--help`、`--version` 成功退出 0。

## 2. 交互主页与选书

交互界面采用暖橙色强调、`❯` 提示符和紧凑的内联菜单，沿用终端背景，保留上方输出。主页可直接输入关键词搜索教材，或输入 `/` 查看命令提示并用 Tab 补全：

| 主页命令 | 行为 |
| --- | --- |
| `/browse` | 清除搜索条件，从所有分类开始浏览 |
| `/search [关键词]` | 搜索教材；省略关键词时打开输入框 |
| `/paste` | 按行粘贴教材页面链接或资源 ID，然后进入下载确认 |
| `/selected` | 查看全部已选教材；Esc 直接返回主页 |
| `/download` | 打开已选教材的下载确认页；未选教材时提示先选书 |
| `/auth` | 打开凭据管理菜单 |
| `/help` | 显示命令与选书快捷键 |
| `/quit` | 正常退出，退出码 0 |

主页 ↑↓ 查阅本次会话的输入历史，历史仅保留在内存中；Ctrl+D 在主页正常退出，Ctrl+C 在交互过程中取消并退出 130。菜单使用 ↑↓ 或 Tab／Shift+Tab 移动，Enter 确认，也可按数字 1–9 快捷选择；Esc 返回。单行输入框按 Enter 确认，多行粘贴框按 Ctrl+D 或 Ctrl+S 确认，凭据输入隐藏。

设置 `NO_COLOR` 时使用无颜色、无光标控制的编号式文本向导，提供搜索选书、粘贴链接和临时凭据入口；主页斜杠命令用于正常终端交互模式。显式的 `search`、`download` 等子命令仍按参数执行。

交互界面启动时自动检查一次本地凭据：系统凭据库已有凭据则静默；缺失或后端不可用时一次性显示导入引导（可“稍后再说”，本会话不再重复）。引导提供“从浏览器自动导入”与“粘贴 JSON”两种方式并附获取步骤；浏览器导入只在用户明确选择时扫描本机 Chromium 系浏览器本地存储中平台域的记录，不读取其他站点数据，也不静默读取。解析失败显示原因与重试指引；钥匙串保存失败提供“仅本次使用”回退。主页状态栏与下载确认页始终显示当前凭据状态（不含秘密值）。进入下载前展示选中教材、保存目录及是否添加书签；用户确认后开始。

按目录浏览流程：

1. 显示目录快照来源、更新时间及新旧状态；读取本地缓存，无可用缓存时联网获取。
2. 逐层显示实际存在的分类，例如“初中 → 数学 → 人教版 → 七年级”。层级和选项来自目录数据，不要求所有教材拥有相同层级。
3. 教材列表显示名称、完整分类路径及资源 ID；长名称可换行，不能截断到无法区分版本。
4. 用户可逐本选择、全选当前结果、清空当前结果选择、返回分类或继续搜索。
5. 打开下载前检查页，选择输出目录与书签选项，开始下载并显示结果摘要。

选书按键：方向键移动，PageUp／PageDown 翻页，空格切换选择，回车进入分类或继续，`/` 修改搜索，`a` 全选当前结果，`u` 清空当前结果，`v` 查看全部已选，`d` 打开下载确认，Esc 返回上一步，Ctrl+C 取消并退出 130。分类行的空格选择／取消该分类下当前可见的教材；只选择了部分教材时显示半选状态。从浏览列表按 `v` 打开的已选视图在 Esc 后返回原浏览位置。

搜索和分类筛选不能丢失隐藏的已选教材。“全选当前结果”仅影响当前结果，“清空当前结果选择”不能清除隐藏选择。始终显示总已选数；当总已选数与当前结果中的已选数不同时，一并显示后者，避免把总数误读为当前筛选下的选择。在分类行上按空格会勾选或取消该分类下当前可见的全部教材，可能一次改变数百本。提供查看全部已选项的入口；在全部已选视图中执行“清空当前结果”即一次清空全部已选。以资源 ID 集合维护选择，不能以显示名称或当前页面索引作为主键。

`browse --query TEXT` 从指定搜索结果开始，后续仍可改搜索条件及返回目录。空分类不能显示为可下载教材。

## 3. 搜索规范

`search QUERY` 使用缓存中的教材索引，不下载 PDF。`QUERY` 按空白分词并进行大小写折叠；全部关键词必须出现在教材标题与完整分类路径构成的文本中，属于子串 AND 匹配，不做拼音、模糊纠错或相关性排序。

`--stage`、`--subject`、`--edition`、`--grade` 是相应维度的完整显示名匹配（可大小写折叠），并与关键词条件取交集。未提供的维度不限；教材缺失某维度时不能匹配该维度条件。维度按标签含义映射，不能依靠树的固定深度或标题猜测年级。平台尚未提供对应维度时明确告知；无匹配返回空结果并退出 0。

分页在所有过滤之后执行。`--limit` 默认 20，范围 1–1000；`--offset` 默认 0，必须非负。结果按完整分类路径、标题、资源 ID 排序，确保同一快照上的分页稳定。人类可读输出显示总数、本页范围、资源 ID、名称、分类路径和目录更新时间。

规范资源 ID 优先使用目录记录的 `content_id`，缺失时使用 `id`；同时保留原始目录记录 ID 为 `catalog_id`。规范 ID 和页面 URL 可以直接解析，不要求目录先获取成功。旧目录 ID 仅在已有可用索引能消歧时映射，不能为此强制刷新整个目录；存在别名冲突或无法确认别名时返回输入错误，不能猜测。下载页面链接由平台资源类型和规范 ID 构造。多路径教材必须在同一条路径内联合满足关键词及维度条件。

## 4. 下载规范

### 输入与预检

- URL 位置参数、重复的 `--id`、`--input` 文件三种来源可以合并；按“位置参数 → `--id` → 文件行顺序”建立队列，保持首次出现顺序。
- 至少提供一项输入。全部输入先解析，文件中无效行附行号返回；输入语法错误或无法消歧的 ID 在发出下载请求前退出 2，避免脚本发生意外的部分执行。
- 合法 ID 对应的教材已下架、详情解析失败或没有 PDF，属于执行阶段失败，记录到该项结果，其他项继续。
- 页面 URL 仅允许受支持的平台域名及教材详情路径；不能把任意 URL 当作下载入口。页面输入先提取 ID，再经平台适配层解析文件，避免从输入直接发送凭据。
- 一个资源可能包含多个 PDF，解析后按“规范资源 ID + artifact ID”再次去重。artifact ID 优先取平台文件标识；无标识时取适配层生成的稳定身份，不能使用带易变签名的整个 URL 作为身份。

### 保存与进度

`--output`／`-o` 指定输出根目录，默认当前目录下的 `textbooks/`。首次保存按规范分类路径中的学段、学科、版本组织子目录；缺失层级跳过。规范路径选择规则见架构文档，不随当前搜索或选择入口变化；相同资源已有可信清单时沿用其安全相对路径。文件名来自教材标题，进行跨平台合法化，并在末尾附短资源 ID；同资源的多个 PDF 仍冲突时追加稳定 artifact 后缀。

`--jobs` 范围 1–3，默认 2；限制的是同时下载的文件数。单次请求最多尝试 3 次（包含 CDN 切换），连接超时 10 秒、读取超时 60 秒；认证失败不盲目切换 CDN。`--bookmarks` 默认关闭，开启后尝试添加平台章节书签。PDF 下载成功但书签处理失败时保留原始有效 PDF，任务保持 `completed`、显示警告，并记录 `bookmarks_applied=false`。没有章节数据时标记 `unavailable`，不视为下载失败。

临时内容先写入输出目录内的临时文件，响应与轻量 PDF 检查通过后原子发布为最终文件；只有显式覆盖时才能替换已有文件。轻量检查指非空、前 1024 字节内出现 `%PDF-` 头并拒绝明显 HTML，不等同完整 PDF 结构验证。失败或 Ctrl+C 时清理本次未完成临时文件，保留已完成文件；重试从头下载，不承诺字节续传。重试时显示尝试序号并重置本次已收字节，进度只在一次尝试内单调。

TTY 进度显示每项的排队、解析、下载、书签、完成／跳过／失败状态，以及可获得的大小、速度和已下载量；服务器不提供大小时显示已接收字节数。非 TTY 下输出简洁的阶段与结果消息，全部写入标准错误。

### 去重与覆盖

下载清单只记录资源／artifact 身份、相对路径、文件大小、校验摘要、完成时间及书签结果，用于文件验证和跳过判断，不用于恢复中断任务。清单不得记录凭据或带鉴权参数的链接。

先解析当前源元数据，比较清单身份、可用修订/摘要信息和书签选项；本地文件还需通过记录的大小、摘要和轻量 PDF 检查，才能返回 `skipped`。没有可比较的平台修订或摘要时，可在本地验证通过后跳过，但必须警告“平台内容版本未确认”。只有同名文件、没有清单，不能视为已下载；默认视为路径冲突并报告失败，要求指定其他输出目录或显式使用 `--overwrite`。清单指向的文件缺失时可以重新下载；现存文件校验失败、源版本变化或处理选项不一致时，需要显式覆盖，不能擅自替换。

`--overwrite` 强制重新下载命中目标的文件并更新清单，最终替换仍在新文件校验成功后进行。该选项不删除本次队列之外的文件。使用 `filelock` 对整个输出目录的批次加锁，锁文件和 SQLite 清单位于 `<output>/.textbook/`。已有其他进程占用时返回 `OUTPUT_BUSY`、退出 1，不开始下载。

## 5. 目录、凭据和诊断命令

| 命令 | 行为 |
| --- | --- |
| `catalog refresh` | 联网校验并完整更新目录；成功后原子替换缓存，失败保留原缓存并退出 1 |
| `catalog status` | 不联网，显示缓存是否存在、来源、更新时间、教材数和缓存新旧状态；无缓存也是有效状态，退出 0 |
| `auth import` | 隐藏输入或 `--file FILE` 读取 UTF-8 JSON；`--file -` 从标准输入读取。验证必需字段后保存到操作系统 keyring |
| `auth grab` | 扫描本机 Chrome/Chromium/Edge 本地存储中平台域的凭据记录并保存到系统钥匙串；来源主机名按平台域名精确校验，先按数据库还原每个键的最新状态（先写后删的记录不导入）。同一浏览器配置内取写入序号最新的一组；多个浏览器配置都有记录时，因写入序号跨配置不可比，让用户选择来源（非交互环境返回错误与手动导入指引）。未找到时给出手动导入指引。只在用户显式执行时读取，不读取其他站点数据 |
| `auth status` | 只显示有无凭据、存储后端与可判断的状态；不联网、不显示凭据值，不能把“本地存在”声称为“平台验证有效” |
| `auth clear` | 清除本项目保存的凭据和进程内副本；本来不存在时仍成功，不修改参考项目的配置 |
| `doctor` | 只做本地诊断：检查版本、配置与缓存位置、默认输出目录能力及 keyring 后端可用性；不联网、不读取秘密值、不打印鉴权头；发现必要能力故障退出 1，纯状态信息退出 0 |

凭据 JSON 包含 `access_token`、`mac_key`、`diff`，按适配层校验；不接受命令行 `--token SECRET` 形式，避免进入 shell 历史或进程列表。配置目录与参考项目隔离。

keyring 保存失败不能静默改存明文。交互向导可以明确选择“仅本次使用”，继续当前下载；独立 `auth import` 命令因进程即将退出，必须报告未持久化并退出 1，并提示可在向导中使用临时凭据，不能显示导入成功。`auth clear` 因存储后端故障无法删除已存在凭据时退出 1。

无 keyring 的服务器可用 `download --credentials-file FILE` 读取三项凭据 JSON，仅在当前命令内存中使用、不持久化；该来源优先于已保存凭据。参数只包含文件路径，不接受凭据值。该选项不支持 `-` 标准输入别名，避免与 `--input -` 争用输入流；文件缺失或内容无效时在下载前返回明确错误，不回退到其他凭据掩盖问题。

目录缓存 TTL 为 24 小时，从最近成功检查时间 `checked_at` 计算；另保存内容获取时间 `fetched_at`。过期时尝试刷新，失败使用可解析的旧快照并输出警告、显示两个时间，不能更新成功检查时间。离线浏览和搜索不能仅因缓存过期而失败。缓存缺失且联网失败时，目录依赖命令退出 1，直接 URL 下载仍可独立尝试。显式执行 `catalog refresh` 失败仍退出 1，不能以旧缓存存在冒充刷新成功。

## 6. 输出与退出码

仅 `search --json` 和 `download --json` 在首版提供 JSON。标准输出必须恰好是一个 UTF-8 JSON 对象，末尾换行；进度、日志和警告只写标准错误，不能混入 JSON。显式使用 `--json` 后，包括参数错误在内的可处理失败也使用相同对象封装；`--help` 和 `--version` 保持普通文本。

统一封装：

```json
{
  "schema_version": 1,
  "command": "search",
  "ok": true,
  "data": {},
  "warnings": [],
  "error": null
}
```

顶层 `error` 为 `null` 或包含稳定机器码 `code`、可读 `message` 的对象；批量部分失败时给出批次级错误，逐项原因放在 `data.results`。输入错误可附 `input`／`line`，URL 必须先脱敏。`ok` 仅当退出 0 时为 `true`。未知大小、缺失维度等使用 `null`，不能用猜测值或空字符串冒充。

执行前错误使用 `data=null`，例如参数或凭据文件输入无效；进入执行后保留已经形成的结果。以下 `data` 字段要求适用于执行结果，不要求参数错误生成空的业务结果。

`search` 的 `data` 必须包含 `catalog`（`updated_at=fetched_at`、`checked_at`、`source`、`stale`）、`total`、`limit`、`offset`、`items`。每项包含 `resource_id`、`title`、`stage`、`subject`、`edition`、`grade`、`category_path`、`category_paths`、`matched_category_paths`、`primary_category_path`、`page_url`。全部路径和匹配路径分别保留；`category_path` 为排序后的第一条匹配路径，四个单值分类字段取该路径的可确认值，缺失为 `null`。`primary_category_path` 按架构定义，稳定排序和保存使用它，不必与展示路径相同。

`download` 的 `data` 必须包含 `summary` 和 `results`。summary 至少有 `requested`（去重后的资源数）、`artifacts`（实际解析出的支持文件数）、`completed`、`skipped`、`failed`、`cancelled`；解析失败而未产生 artifact 的资源也必须出现在 results 中，其 `artifact_id` 为 `null`。四种终态计数合计等于 `results` 长度，不要求等于 `artifacts`。每项包含 `resource_id`、`artifact_id`、`status`、`path`、`bytes`、`bookmarks`、`bookmarks_applied` 和可空的 `error`；文件状态为 `completed`／`skipped`／`failed`／`cancelled`，书签状态为 `disabled`／`added`／`unavailable`／`failed`。逐项 error 同样使用 `code`／`message`。不输出私有下载直链或凭据。

| 退出码 | 语义 |
| --- | --- |
| 0 | 成功，包括无搜索结果、经文件验证后跳过、或仅书签警告 |
| 1 | 一般失败；批量全部失败且不全是凭据失败 |
| 2 | 参数、输入、歧义 ID、缺少 TTY 等用法问题 |
| 3 | 平台认证或资源权限问题，或下载全部因这类问题失败；凭据 JSON 输入错误用 2，本地存储后端故障用 1 |
| 4 | 批量部分成功：至少一项完成或有效跳过，同时至少一项失败 |
| 130 | Ctrl+C 中断，优先于其他结果 |

批量判定以最终执行项为准；资源解析失败算失败项。失败只有凭据错误时用 3，其他全失败用 1。已下载的有效 PDF 仅书签失败属于警告，退出 0，但 JSON 必须保留该状态。错误文案不能显示 traceback；调试日志也必须对 Token、MAC、Cookie、鉴权头及敏感查询参数脱敏。

## 7. 使用示例与验收

以下命令可直接使用；下载示例中的资源 ID 和文件路径需替换为实际输入：

```sh
# 交互选书
textbook

# 搜索并供脚本读取
textbook search "数学 七年级 下册" --stage "初中" --edition "人教版" --json

# 同时接受 URL、ID 和文件输入；示例 ID 是占位值
textbook download 'https://basic.smartedu.cn/tchMaterial/detail?contentType=assets_document&contentId=EXAMPLE_ID' --id ANOTHER_ID --input books.txt -o ./books --bookmarks

# 从文件导入用户自行取得的凭据，不在参数中粘贴秘密
textbook auth import --file credentials.json
textbook download --input books.txt --credentials-file credentials.json
textbook catalog refresh
textbook doctor
```

最低验收覆盖：三平台终端启动；无 GUI 导入；TTY／非 TTY 分支；动态分类与空分类；搜索分页稳定；隐藏选择保留；多输入合并和双层去重；无清单同名文件冲突；有效文件跳过、缺失文件重下、损坏现存文件须授权覆盖；凭据保存失败；JSON 单对象输出与脱敏；批量退出码矩阵；Ctrl+C 清理及已完成文件保留。真实下载烟测使用用户有权访问的 PDF，并与离线响应样本测试分开。
