# 需求与范围

状态：已实现；离线验收与 macOS 真实凭据下载验收完成，Windows/Linux 待验证。基线日期：2026-10-22。

## 1. 目标与场景

用户无需启动桌面工具，即可从终端找到需要的电子教材并下载到本地。既支持教师、家长通过菜单逐步选书，也支持使用者以明确参数执行重复下载任务。

首版覆盖四个场景：

1. 按平台实际分类浏览课本，选择多本后批量下载。
2. 使用“数学 七年级 下册”等关键词搜索，确认版本和分类后下载。
3. 已有教材预览页面链接或资源 ID，直接下载或从文本清单批量读取。
4. 在无图形桌面的环境中运行命令，取得可解析的结果和明确退出码。

首版实现质量以“可解释、可验证地完成选定教材的下载”为标准，不以批量收集全平台资源为目标。

## 2. 功能需求

| 编号 | 功能 | 首版行为 |
| --- | --- | --- |
| FR-01 | 目录获取 | 获取官方分类、版本索引及分片，转换成独立的数据模型；空分类不能成为教材 |
| FR-02 | 目录缓存 | 有效期 24 小时；支持主动刷新和查看缓存时间；刷新失败保留完整旧缓存 |
| FR-03 | 搜索 | 名称与完整分类路径参与匹配；空格分隔关键词按 AND 匹配；支持学段、学科、版本、年级过滤 |
| FR-04 | 分类浏览 | 跟随实际分类树逐级显示；有缺失或额外层级时仍能工作，不固定四级菜单 |
| FR-05 | 多选 | 按资源身份去重；搜索、翻页不丢已选项；“全选当前结果”只作用于当前可见结果 |
| FR-06 | 输入解析 | 接受平台教材预览 URL、资源 ID、按行存放 URL 或 ID 的 UTF-8 文件；普通教材 PDF 以外的资源明确提示不支持 |
| FR-07 | 凭据使用 | 导入用户自己的 `access_token`、`mac_key`、`diff`；支持安全持久保存或明确的本次使用。凭据可经粘贴/文件手动导入，也可由用户显式触发“从浏览器自动导入”；后者只读取本机浏览器中平台域的本地存储记录，不在启动时静默读取 |
| FR-08 | 批量下载 | 展示逐项状态与总体结果；并发默认 2，上限 3；有限重试；失败不阻止无关任务完成 |
| FR-09 | 文件校验 | 校验可用的大小和平台 MD5，拒绝明显非 PDF 响应，记录最终文件 SHA-256；校验失败不生成新的完成文件 |
| FR-10 | 文件管理 | 安全文件名、分类目录、临时文件与完成清单；验证已有文件后才跳过，覆盖必须有明确参数授权 |
| FR-11 | PDF 书签 | 用户显式开启；书签失败时保留已校验的原 PDF，结果包含警告，不丢失原始下载 |
| FR-12 | 取消与重试 | Ctrl+C 停止本批任务并清理其临时文件；保留完成文件；向导可重试失败项，重试从头下载 |
| FR-13 | 自动化输出 | 搜索和下载提供单个 JSON 结果对象；诊断、进度写入 stderr；无终端时不等待菜单或隐藏输入 |
| FR-14 | 诊断 | 检查版本、配置位置、缓存状态、凭据存储后端和输出目录能力；不输出凭据或环境变量全集 |

过滤条件只使用平台实际提供并可确认的字段；缺失年级的教材不能仅凭标题猜测为某年级。教材可以属于多个分类路径，搜索结果按规范资源 ID 合并，同时保留其路径信息。

## 3. 非功能需求

| 编号 | 要求 | 验收含义 |
| --- | --- | --- |
| NFR-01 | 无 GUI 运行依赖 | 核心、命令及测试可以在不安装 Tkinter、没有显示服务的环境中运行 |
| NFR-02 | 跨平台 | 三平台覆盖中文路径、长名称、文件锁、凭据后端失败及 Ctrl+C 行为 |
| NFR-03 | 可维护 | 平台接口集中于适配层，核心服务不依赖终端控件或上游 GUI 模块 |
| NFR-04 | 有界等待 | HTTP 默认连接超时 10 秒、读取超时 60 秒；可重试请求总尝试次数最多 3 次 |
| NFR-05 | 凭据保护 | 不通过参数直接传 Token；配置、缓存、下载清单、日志及 JSON 结果不包含凭据 |
| NFR-06 | 文件可靠性 | 最终发布前失败不改动原文件；发布成功后清单登记失败，保留新的完整 PDF 并报告错误；并发进程不能同时写同一输出根目录 |
| NFR-07 | 可测试 | 业务测试默认离线，平台响应有脱敏样本；真实网络测试单独启用 |
| NFR-08 | 可观察 | 区分输入、网络、认证、平台结构变化、文件和校验错误，结果说明可采取的下一步 |

读取超时限制的是相邻读取之间的等待时间，不是整本教材的总下载时长。单次 Ctrl+C 发出取消后，阻塞中的网络调用可能仍需等待当前超时；不得宣称任意时刻都能瞬间停止。

## 4. 首版不包含的功能

- 自动登录、验证码处理、自动刷新凭据，以及启动时静默读取浏览器数据。浏览器凭据导入必须由用户显式触发（命令或向导按钮），且只读取平台域的本地存储记录。
- 专题课程、视频、配套音频和完整课程包下载。
- HTTP Range 续传、保留半成品继续下载、跨次启动恢复任务队列。
- 定时任务、云端服务、远程账户管理、教材托管和内容再分发。
- 默认遍历并下载全平台资源、通过更换节点规避无访问权限的响应。
- 网络共享盘、对象存储挂载上的文件锁与原子提交保证。

## 5. 关键决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 项目组织 | 独立项目，按模块选择性迁入核心逻辑 | 避免运行时携带图形界面和桌面打包依赖 |
| 网络模型 | 同步 HTTP + 小规模线程池 | 上游已有成熟行为，首版无需引入整套异步模型 |
| 凭据入口 | 系统凭据库、向导临时输入、单次下载凭据文件、浏览器本地存储显式导入 | 同时支持个人电脑和没有凭据服务的服务器；浏览器导入免去手动粘贴，但仅在用户点击时读取平台域记录 |
| 已下载判断 | 资源身份 + 清单 + 本地校验 + 可用版本信息 | 同名文件存在不足以证明下载完整或内容一致 |
| 后续演进 | 先验证完整下载流程，再增加续传、音频 | 减少首版资源类型与状态组合 |

## 6. 已知风险与验证边界

1. 目录、详情和文件地址来自平台网页使用的数据端点，本文没有确认存在面向第三方的稳定公开 API 合约；接口变化需要持续适配。
2. 有些资源可能允许匿名访问，但匿名成功不作为产品保证。认证失败也不能直接等同于凭据过期，可能存在资源权限限制。
3. HTTP 400 可能与参数、签名或限流有关；错误处理需保留判断依据，不能统一提示“Token 过期”。
4. 平台未提供可验证修订标识时，不能证明本地教材一定是平台最新内容。工具应显示该限制，并允许显式重新下载。
5. 公开元数据与 macOS 真实凭据端到端下载已于 2026-10-22 验收（范围与限制见[实现与验收记录](06-implementation-status.md)）；Windows/Linux 安装与跨平台人工核对待完成，发布前按测试文档记录范围和日期。

逐项验收与发布门槛见 [测试与验收](05-testing.md)，命令细节见 [命令与交互设计](03-cli-design.md)。
