## 统一设计决策

| 项目 | 首版约定 |
| --- | --- |
| 暂定名称 | 项目 `textbook-cli`，Python 包 `textbook_cli`，命令 `textbook`；发布前确认名称可用性 |
| 平台 | Python 3.10+；Windows、macOS、Linux；运行和核心测试不依赖 Tkinter 或图形显示服务 |
| 资源范围 | 普通电子教材 PDF，资源类型 `assets_document` |
| 入口 | 无参数且处于交互终端时进入向导，同时提供独立子命令 |
| 默认下载 | 保存到当前目录下的 `textbooks/`；并发 2，允许 1–3；PDF 书签默认关闭 |
| 目录 | 动态分类、多关键词搜索、本地缓存；缓存有效期 24 小时 |
| 凭据 | 系统凭据库优先；无可用后端时，支持当前交互会话或 `download --credentials-file` 临时使用 |
| 文件 | 下载到临时文件，校验后提交；依据资源身份和下载清单判断已有文件 |
| 延后功能 | 配套音频、课程资源、自动登录与凭据刷新、断点续传、跨次启动恢复任务 |

“下载清单”只登记已完成文件并支持校验、去重，不代表已经具有任务恢复能力。代码复用不意味着平台接口或匿名访问方式具有长期可用保证。
