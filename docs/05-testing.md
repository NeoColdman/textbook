# 测试与验收

本文定义新项目的测试计划。**新项目尚未实现；下面的测试名称、命令示例和完成门槛均是待实现要求，不是已有测试结果。** 下载清单仅用于校验与去重，验收不包含断点续传或跨次任务恢复。

## 1. 已有验证事实与边界

2026-10-22 对本地参考项目进行了代码评估和验证：

| 项目 | 记录 |
| --- | --- |
| 参考项目 | `tchMaterial-parser` v4.4 |
| 提交 | `244170e17bf8bc97401f65e04d261533d252572a` |
| 公开元数据 | tags 与 version 请求返回 HTTP 200；索引包含 4 个分片 |
| 数据抽查 | 首个索引分片有 1000 条记录；一年级《道德与法治》详情包含 PDF 条目 |
| 非 GUI 测试 | 121 项通过，另有 34 个 subtests 通过 |
| 窗口测试 | 15 项因当前 Tcl 环境失败，尚不能据此确认窗口功能是否正常 |

上述事实只反映该参考版本与当次环境。公开 JSON 可读取不等于私有 PDF 可下载；参考项目测试通过也不等于新项目已经实现或验收。

## 2. 测试分层

| 层级 | 目的 | 外部依赖 | 运行方式 |
| --- | --- | --- | --- |
| 单元与契约 | 数据转换、签名、决策、输出协议 | 无网络；脱敏样本与假时钟 | 每次改动和 CI |
| 本地 HTTP 集成 | 真实请求、传输、超时、取消与重试 | 仅本机临时 HTTP 服务 | 每次下载相关改动和 CI |
| CLI 端到端 | 参数、向导、输出、退出码与核心串联 | 假平台适配器与本机服务 | CLI 改动和 CI |
| 三平台安装 | 打包、中文路径、终端与 keyring 差异 | Windows/macOS/Linux | 发布前 |
| 真实平台抽查 | 当前目录及实际私有文件链路 | 网络；有权使用的测试者凭据 | 人工显式运行，默认关闭 |

默认测试必须不连接真实平台、不读取用户现有凭据、不修改用户配置。配置、缓存、下载目录和清单使用测试专用临时目录；keyring 使用替身。真实平台测试与日常 CI 分开，避免将平台波动误判为本地代码回归。

## 3. 离线契约样本

样本应来自必要且脱敏的平台响应或人工构造数据，附来源接口类型、采集日期、适配版本和预期结果。不要保存访问凭据、认证请求头或用户资料；不将教材 PDF 正文加入仓库。

至少覆盖：

- 分类标签、版本描述、4 个索引分片的结构，以及分片顺序变化和重复资源 ID。
- 普通电子教材 PDF、同名不同版本、多文件条目、无 PDF、资源移除和字段缺失。
- `ti_size`、`ti_md5`、revision 等信息存在、缺失、类型错误或取值无效。
- 存储地址的不同表示、中文文件名、空格、URL 编码和多个 CDN 地址。
- 书签 mapping、目录树、页码缺失、嵌套目录和无可用章节。
- 平台结构不符合预期、非 JSON 响应、错误响应和部分分片失败。

样本验证只说明适配器能处理已知输入；平台联通性由真实平台抽查单独证明。

## 4. 核心测试矩阵

### 4.1 平台、目录与缓存

| 场景 | 预期结果 |
| --- | --- |
| 正常标签、版本和多分片索引 | 合并为稳定模型；教材 ID 可追溯；筛选得到预期集合 |
| 同名、不同版本或不同文件条目 | 保持独立身份，不按标题合并 |
| 个别记录字段类型异常（如 `tag_list` 非数组、`tag_dimension_id` 为数组/对象） | 按结构异常隔离该记录并计数警告；不抛 TypeError 中断搜索，旧缓存回退仍可用 |
| 分类标签文件中维度 ID 类型异常 | 转为结构化错误触发旧缓存回退；不因不可哈希键抛 TypeError 崩溃 |
| 分片失败、响应截断、结构变化 | 明确失败；不把不完整新目录覆盖为有效缓存 |
| 缓存不足 24 小时 | 使用有效缓存，状态与时间正确 |
| 缓存达到或超过 24 小时 | 按 TTL 策略刷新；边界用假时钟验证 |
| 显式刷新 | 即使缓存未过期也请求更新 |
| 平台版本不变、分类发生变化 | 重新构建快照；不能仅更新检查时间而丢失分类变化 |
| 更新失败但旧缓存可读 | 使用旧缓存并展示时间、过期与降级状态 |
| 显式刷新失败但旧缓存可读 | 保留完整旧快照，命令仍退出 1；失败不能更新 checked_at |
| 缓存损坏，且网络不可用 | 明确目录不可用，不返回假成功空列表 |
| 写缓存中断或磁盘失败 | 已有有效缓存保持可读，错误可见 |
| 详情无 PDF、404 或字段不符 | 区分无支持文件、资源不可用与适配错误 |

### 4.2 凭据与请求

| 场景 | 预期结果 |
| --- | --- |
| 正确三字段凭据 | 校验后保存到系统 keyring，不回显秘密 |
| 缺少字段、空值或 diff 类型错误 | 输入失败；不覆盖原有效凭据 |
| keyring 锁定、不可用、读写或删除失败 | 明确存储错误；无静默明文回退 |
| 持久导入时 keyring 不可用 | 退出 1；不假装已保存，不提供跨命令内存凭据 |
| 下载指定 `--credentials-file FILE` | UTF-8 三字段 JSON 优先于 keyring，仅本命令内存使用；配置与清单均无秘密 |
| 凭据文件不可读或 JSON 非法 | 退出 2；不输出文件内容，不回退到另一份凭据继续下载 |
| 向导明确选择“仅本次使用” | 本次下载可用；退出后不保存到 keyring、配置或清单 |
| 浏览器导入：来源主机名伪装（如 `smartedu.attacker.example`） | 按解析出的主机名精确校验平台域名；不接受字节子串匹配，第三方域记录不导入 |
| 浏览器导入：先写入后删除的凭据记录 | 按数据库、键和序号还原最新状态后再提取；已删除记录不复活为可用凭据 |
| 浏览器导入：日志 32KiB 块尾填充 | 跳过不足记录头的填充并对齐下一块；后续块中的凭据记录不被遗漏 |
| 浏览器导入：多个浏览器配置都有记录 | 写入序号只在同库内比较；让用户选择来源（非交互返回明确错误），不自动宣称“最新” |
| 凭据清除 | 只清除本项目凭据；之后请求不携带旧秘密 |
| 中文编码路径、查询串、固定 nonce、时钟差 | 签名与独立固定向量一致 |
| 请求未显式配置超时 | 使用连接 10 秒/读取 60 秒；所有元数据与下载请求一致 |
| 日志、异常、JSON、URL 带秘密 | 已知凭据和查询参数秘密均被脱敏 |
| 用户输入非平台 URL、响应跳转至未允许主机 | 拒绝请求；秘密头不跨域泄露；允许的认证重定向按新 URL 重签 |
| HTTP 400 | 保留具体错误与上下文，不直接断言凭据过期 |
| HTTP 401/403 | 按凭据/权限问题报告，认证问题退出 3；不切换 CDN 规避 |
| 429、502/503/504 或暂时网络故障 | 按架构分类及等待策略有限重试；其他状态不无条件重试 |
| 429 的 Retry-After 在 60 秒内、超过 60 秒及等待中取消 | 分别等待后有限重试、结束当前任务并报限流、及时取消 |
| 多镜像且多次失败 | 一次逻辑操作总请求尝试不超过 3 次，包含初次请求 |

重试测试使用假时钟或可注入等待器，断言尝试次数、等待时长和终态，不依赖长时间真实等待。400 的有限重试策略必须与架构一致，不能把错误文本等同于认证状态证据。

### 4.3 下载、校验与清单

| 场景 | 预期结果 |
| --- | --- |
| 小文件、大于一个数据块的文件 | 流式写入；同一 attempt 内进度字节单调；完成后文件正确 |
| 下载中断后重试 | downloading 回到 connecting，attempt 增加，本次已收字节归零；总请求预算仍最多 3 次 |
| 默认与边界 jobs 值 | 默认最多 2 个并行任务；1–3 可用；0、4 等非法值拒绝 |
| 长度已知、未知、压缩响应 | 正确处理大小和进度；不拿压缩传输长度误判解压后的内容 |
| 服务器提前断流、读取超时 | 不发布半成品；失败原因与已传输字节可见 |
| 平台大小或 MD5 不匹配 | 完整性失败；不生成成功清单条目 |
| 平台大小/MD5 缺失 | 明确可验证程度；仍计算原文件 hash 与最终 SHA256，不虚报平台校验通过 |
| HTTP 200 返回 HTML、空正文或没有 PDF 头 | 轻量 PDF 检查失败，不发布文件；不宣称轻量检查验证了完整 PDF 结构 |
| 书签关闭 | 原文件内容保持一致，最终 SHA256 对应实际落盘文件 |
| 书签开启 | 先核对原文件，再改写；原文件 hash 与最终文件 hash 分开记录 |
| 书签处理失败 | 保留通过传输校验的原始 PDF，以 warning 完成并登记 `bookmarks_applied=false`；不丢失原文件 |
| 书签非法页码与嵌套章节 | 按章节处理规则跳过或报告，不把错误书签写入其他页 |
| 父章节缺页码但子章节有效、或全部章节无效 | 父节点缺页码只跳过自身书签，仍写入有效子节点；未写入任何书签时保留原 PDF 并如实报告失败，不虚报 `bookmarks_applied=true` |
| 同标题、同目录且资源 ID 前缀相同的两本教材分批下载 | 分配路径时检查下载清单中其他资源占用的路径并延长后缀；不报无意义冲突，也不在 `--overwrite` 时替换对方文件 |
| 同资源、同版本、清单与本地 hash 一致 | 可去重跳过，并提供可追溯理由 |
| 同标题不同 ID、revision 改变、本地文件被修改 | 不按同名或存在即跳过 |
| 清单文件缺失、现存文件损坏 | 缺失时可重下；现存损坏文件默认冲突，需显式 --overwrite 才替换 |
| 同本教材通过不同分类或搜索入口选中 | 首次保存用同一规范分类路径，已有可信清单时沿用其相对路径 |
| revision 或平台 hash 缺失 | 按未知值策略处理，不宣称已确认是最新版 |
| 清单损坏、SQLite 事务失败或文件原子替换失败 | 明确错误；已有有效记录不被半提交内容覆盖 |
| 文件完成后清单登记失败 | 保留完整 PDF 并报告任务失败、清单未登记；重跑不盲目认领 |
| 目标路径已有文件但无有效清单 | 默认冲突；仅显式 `--overwrite` 可替换，最终替换前失败不改变原文件；替换后清单提交失败保留新完整文件并报错 |
| 无覆盖参数且提交前有其他程序新增目标 | 独占发布失败，不覆盖新目标；不能以先检查再替换规避该测试 |
| 默认与缺失分类的输出路径 | 默认 `./textbooks`，按学段/学科/版本存放；缺失层级省略，文件名清洗并带短资源 ID |
| 两个工作线程同时请求 | 各自使用独立 requests.Session，不共享可变会话 |

下载清单要核对资源 ID、文件条目 ID、revision、本地路径、原文件 hash、最终文件 SHA256 及状态。书签开启时，平台 MD5 与最终 PDF 的 hash 不应混为一项。

平台 MD5 只作内容传输对照，不是安全认证；最终 SHA256 用于后续本地完整性核验。SQLite 清单位置为 `<output>/.textbook/manifest.sqlite3`，仅登记 completed 状态。

### 4.4 取消、重试与存储故障

| 场景 | 预期结果 |
| --- | --- |
| 排队、连接、传输、退避等待时取消 | 停止新请求；可取消等待及时结束；读取中的操作受 60 秒读取超时约束 |
| 最后一个数据块之后、进入 committing 前取消 | 不发布未确认完成的文件，不登记成功 |
| committing 临界区取消 | 延后处理取消，先完成文件原子替换与 SQLite 提交；不因取消产生半提交 |
| 部分已完成、部分未完成时取消 | 已完成文件保留；未完成临时文件清理；退出码 130 |
| 单个任务失败后继续批次 | 其他任务可完成；结果逐项可追溯；退出码反映部分成功 |
| 重试失败项 | 仅选定失败项重新下载；不自动恢复上次临时字节 |
| 输出目录无权限、磁盘满、创建临时文件失败 | 原文件不被破坏；任务失败信息可操作 |
| 清理临时文件失败 | 保留可定位的错误提示；不得静默丢弃清理错误 |
| 另一个进程占用临时文件或目标被新增 | 不覆盖不属于本任务的临时文件，不造成并发路径冲突 |
| 清单提交前后模拟进程中断 | 只有已发布且核验一致的条目能用于后续去重 |
| 两进程使用同一输出根目录 | 平台原生锁保证仅一个批次运行；第二个立即报 `OUTPUT_BUSY`，不写下载文件与清单 |
| 两进程使用不同输出根目录 | 各自独立运行，锁与清单互不影响 |

双进程测试必须实际启动两个进程，不能只模拟线程锁。首版验收范围为本地文件系统，不对网络共享盘的锁语义作通过承诺。

## 5. CLI 与跨平台验收

### CLI 输出协议

- 参数错误、凭据问题、完全失败、部分成功和用户取消分别验证退出码：2、3、1、4、130；完全成功为 0。
- 非 TTY 不自动提示输入；缺少必需参数时直接返回明确错误。
- JSON 模式 stdout 仅输出一个可整体解析的 JSON 对象；不混入 ANSI 控制符、进度条、堆栈或凭据。
- JSON 顶层验证 `schema_version=1`、`command`、`ok`、`data`、`warnings`、`error`；下载逐项结果验证 `data.results`，warning 能保留书签降级结果。
- 执行前的 JSON 参数错误使用 `data=null`；多分类搜索在同一路径内联合过滤，输出匹配路径和规范路径，不能显示与过滤条件相矛盾的单值分类。
- 目录 `updated_at` 对应内容获取时间，TTL 使用 `checked_at`；成功复用快照和失败刷新都需要核对两个字段。
- 进度、提示和诊断进入 stderr；renderer 消费核心事件，核心不直接打印。
- 用固定假数据验证筛选、多选、取消选择、长标题和失败项重试；向导与非交互命令得到相同任务结果。
- 状态事件验证 `queued → resolving → connecting → downloading → verifying → [bookmarking] → committing → completed`，以及 skipped、failed、cancelled 终态；每个任务只产生一个终态。
- 默认书签关闭；显式开启且书签失败时，下载仍以 warning 完成，原文件与清单对应。
- `doctor` 只做本地诊断，不访问真实平台、不读取或打印秘密值。

### 三平台检查

| 检查项 | Windows | macOS | Linux |
| --- | --- | --- | --- |
| Python 3.10 与选定较新版本安装 | 必测 | 必测 | 必测 |
| 无 GUI 核心导入与命令运行 | 必测 | 必测 | 必测，包含无 DISPLAY 环境 |
| 中文、空格、大小写冲突与非法文件名 | 必测 | 必测 | 必测 |
| Ctrl+C、输出重定向、颜色关闭 | 必测 | 必测 | 必测 |
| 系统 keyring 保存、读取、清除 | 原生后端实测 | 原生后端实测 | 可用后端实测，并验证缺失后端时明确失败 |
| 目录权限与文件锁冲突 | 必测 | 必测 | 必测 |
| 无 Tk/PIL/psutil/sv-ttk/pywin32 依赖 | 必测 | 必测 | 必测 |

自动化通过静态依赖检查与新进程导入检查验证无 GUI 依赖；仅“不打开窗口”不足以证明安装不需要 GUI 包。

## 6. 真实平台验收记录

人工检查应限于少量有权访问的教材，遵守并发与重试限制。记录测试日期、新项目版本、适配器版本、操作系统、教材资源 ID、所用功能与结果，不记录秘密。

发布前至少完成：

1. 当前目录可读取，筛选结果与少量详情一致。
2. 使用有效用户凭据完整下载至少一本 PDF；核对平台大小/MD5（如有）和实际落盘 SHA256。
3. 开启书签下载一次，核对章节、页数、原文件校验与最终文件 hash。
4. 验证无效或失效凭据被正确报告，400 与其他错误没有被统一说成凭据过期。
5. 取消一次下载，检查文件、清单、输出和退出码。

没有真实凭据时，保持在线检查为“待验证”，可交付离线检查结果。不能通过公开元数据返回 200 推断完整私有资源下载已经验收。
